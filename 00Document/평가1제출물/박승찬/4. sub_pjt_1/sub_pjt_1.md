# [14th-ai1-AI 쇼핑 어시스턴트](https://lab.ssafy.com/sc_park99/14th-ai1)

## 1. 프로젝트 개요

패션 이미지를 업로드하면 AI가 의류 아이템을 탐지하고, 색상을 분석하여 유사한 상품을 추천해주는 대화형 쇼핑 어시스턴트입니다.

## 2. 프로젝트 구조

```
ai-shopping-assistant/
├── app.py                  # 메인 애플리케이션
├── config.py               # 환경 설정 (API 키, 모델 경로 등)
├── utils.py                # 유틸리티 함수 (TokenManager 등)
├── crawl_products.py       # 상품 크롤링
├── requirements.txt        # 패키지 목록
├── fashion_products.csv    # 크롤링 데이터
├── fashion_products.json   # 크롤링 데이터 (JSON)

```

## 6. 실습 과제 구현

### 6.1 색상 인식 기능

탐지된 의류 영역에서 대표 색상을 추출하여 한국어 색상명으로 변환합니다.

#### 구현 함수

| 함수명                     | 설명                                       |
| -------------------------- | ------------------------------------------ |
| `detect_clothing_color()`  | 바운딩 박스 영역에서 색상 추출 메인 함수   |
| `crop_image_by_bbox()`     | YOLO 바운딩 박스 좌표로 이미지 영역 자르기 |
| `extract_dominant_color()` | KMeans 클러스터링으로 대표 색상 추출       |
| `convert_color_to_name()`  | RGB → HSV → 한국어 색상명 변환             |

#### 색상 분류 로직

```
1. 무채색 판별 (채도 < 35인 픽셀이 60% 이상)
   - 밝기(Value) 기준: 검정 < 60 < 회색 < 180 < 흰색

2. 유채색 판별 (KMeans K=3)
   - Hue 구간으로 분류:
     - 빨간: 0~10, 170~179
     - 주황: 11~25
     - 노란: 26~35
     - 초록: 36~85
     - 파란: 86~125
     - 보라: 126~155
     - 핑크: 156~169
```

### 6.2 예산 기반 필터링

사용자의 자연어 예산 조건을 파싱하여 상품을 필터링합니다.

#### 구현 함수

| 함수명                        | 설명                                 |
| ----------------------------- | ------------------------------------ |
| `parse_korean_money_to_won()` | 한국어 금액 표현 → 원(won) 단위 변환 |
| `parse_budget_request()`      | 정규표현식으로 예산 조건 파싱        |
| `normalize_price()`           | 상품 가격을 정수로 정규화            |
| `apply_budget_filter()`       | 예산 조건에 따라 상품 필터링         |
| `generate_budget_response()`  | 예산 기반 응답 메시지 생성           |

#### 지원하는 예산 패턴

| 패턴      | 예시                                    | 모드      |
| --------- | --------------------------------------- | --------- |
| 예산 지정 | "예산 10만원", "예산은 5만원"           | `max`     |
| 이하/미만 | "10만원 이하", "5만원 미만"             | `max`     |
| 이상/초과 | "10만원 이상", "5만원 초과"             | `min`     |
| 범위 지정 | "5만원~10만원", "5만원에서 10만원 사이" | `range`   |
| 더 저렴   | "더 저렴한 걸로", "좀 더 싼거"          | `cheaper` |

#### 사용 예시

```
사용자: "10만원 이상 흰색 드레스"
→ 검색: "흰색 드레스"
→ 필터: 100,000원 이상
→ 결과: 조건에 맞는 상품 표시
```

### 6.3 CLIP 이미지 유사도 검색

업로드된 이미지와 시각적으로 유사한 상품을 찾습니다.

#### 구현 함수

| 함수명                              | 설명                                      |
| ----------------------------------- | ----------------------------------------- |
| `setup_image_vectorstore()`         | CLIP 벡터 저장용 Chroma 컬렉션 생성       |
| `has_valid_image_url()`             | 유효한 이미지 URL 확인                    |
| `download_and_preprocess_image()`   | 상품 이미지 다운로드 및 전처리            |
| `prepare_product_metadata()`        | 상품 메타데이터 준비                      |
| `save_products_with_clip_vectors()` | 상품 이미지 → CLIP 벡터 → ChromaDB 저장   |
| `search_similar_images()`           | 업로드 이미지와 유사한 상품 검색          |
| `merge_and_deduplicate_products()`  | 텍스트/이미지 검색 결과 병합 및 중복 제거 |

#### 동작 흐름

```
1. 이미지 업로드 → YOLO 탐지 → 텍스트 검색
2. 검색된 상품 이미지 → CLIP 벡터 추출 → ChromaDB 저장
3. 업로드 이미지 → CLIP 벡터 추출 → 유사도 검색
4. 텍스트 검색 결과 + 이미지 유사 검색 결과 병합
5. 중복 제거 후 최종 결과 표시
```

## 8. 검색 팁

-   `'최신'`, `'신상'`, `'재고'`, `'실시간'`, `'현재'`, `'오늘'` 키워드를 포함하면 웹에서 새로 검색합니다.
-   검색 횟수는 10회로 제한되어 있습니다.
-   검색 횟수 초과 시 벡터 DB에서 유사 상품을 검색합니다.

## 10. 참고사항

### 색상 인식 한계

-   배경이 바운딩 박스에 많이 포함되면 배경색이 대표색이 될 수 있음
-   패턴/프린트 의류는 대표색이 애매할 수 있음
-   강한 조명 반사 시 밝은 색으로 치우칠 수 있음

### 예산 필터링 한계

-   "더 저렴한" 기능은 이전 검색 결과가 필요함
-   복잡한 조건문 (예: "10만원 이상이면서 20만원 이하")은 첫 번째 조건만 인식

## 11. 프로젝트 회고

### 11.1 배운 점

1. **YOLO 모델 활용법**: 바운딩 박스 좌표를 활용해 특정 영역만 추출하는 기술을 배웠습니다.

2. **색상 분석 알고리즘**: KMeans 클러스터링과 HSV 색공간을 활용한 색상 분류 로직을 구현하면서, 무채색과 유채색을 구분하고 한국어 색상명으로 변환하는 과정을 학습했습니다.

3. **RAG 시스템 구축**: LangChain과 ChromaDB를 연동하여 벡터 기반 검색 시스템을 구축하는 방법을 배웠습니다. 텍스트 임베딩과 이미지 임베딩(CLIP)을 모두 활용하는 하이브리드 검색의 개념을 익혔습니다.

4. **자연어 처리**: 정규표현식을 활용하여 사용자의 예산 조건("10만원 이하", "5만원~10만원")을 파싱하는 로직을 구현하며 실용적인 NLP 처리 방법을 익혔습니다.

### 11.2 아쉬운 점 및 개선하고 싶은 부분

1. **색상 인식 정확도 개선**

    - 현재 바운딩 박스에 배경이 포함되면 색상 인식이 부정확해지는 문제가 있습니다.
    - **개선 방안**: Segmentation 모델을 적용하여 의류 영역만 정확하게 추출한 후 색상을 분석하면 더 정확한 결과를 얻을 수 있을 것 같습니다.

2. **복합 예산 조건 처리**

    - "10만원 이상 20만원 이하" 같은 복합 조건을 제대로 처리하지 못합니다.
    - **개선 방안**: 정규표현식을 개선하거나, LLM을 활용하여 자연어에서 구조화된 필터 조건을 추출하는 방식으로 변경하면 좋을 것 같습니다.

3. **이미지 유사도 검색 성능**

    - 상품 이미지를 실시간으로 다운로드하고 벡터화하다 보니 응답 시간이 느립니다.

4. **대화 컨텍스트 관리**
    - 이전 대화 내용을 충분히 활용하지 못하는 부분이 있습니다.
    - **개선 방안**: 대화 히스토리를 더 효과적으로 관리하고, 이전 검색 결과를 세션에 저장하여 "더 저렴한 걸로" 같은 후속 요청을 더 잘 처리하도록 개선하고 싶습니다.
