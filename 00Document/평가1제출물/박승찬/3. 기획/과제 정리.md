## 1. 아이디어 기획

### AI 스마트 옷장

#### 1) 아이디어 설명

-   매번 무엇을 입어야 할지 고민하게 됨
-   옷이 많아질수록 옷장 속 옷이 한눈에 보이지 않아 원하는 옷을 찾기 어려움
-   전신 거울에 카메라를 **갤럭시 스마트폰의 펀치홀 형태**로 내장하여, 사용자가 입은 옷을 인식하고 코디를 추천

---

#### 2) 아이디어 확장

### [현관] AI 신발 상태 및 외출 추천기 — **Shoe-Butler**

> “비가 올 것 같은데 이 신발을 신어도 될까?”라는 고민을 줄여주는 서비스

-   **불편함**

    -   외출 직전 날씨 확인과 신발 선택이 번거로움
    -   비 오는 날 신발이 젖어 후회하는 상황 발생

-   **AIoT 구현**

    -   **하드웨어:** 라즈베리파이 + 현관 하단 카메라 + 강수 예보 API
    -   **AI:** 이미지 기반 신발 재질 분류 (가죽 / 스웨이드 / 메쉬 등)
    -   **기능:**

        -   사용자가 발을 뻗으면 신발 인식
        -   예: “오늘 오후 3시 비 예보가 있습니다. 스웨이드 재질이므로 다른 신발을 추천합니다.”

-   **젠킨스(Jenkins) 가치**

    -   신규 신발 모델 데이터 학습
    -   침수 취약성, 재질별 관리법을 서버에서 수집 후 모델 업데이트 및 배포

---

### [B2C] AI 옷장 다이어트 — **Re-Style**

> 입지 않는 옷을 객관적으로 분석하고 리폼·중고 판매까지 연결

-   **불편함**

    -   어떤 옷을 안 입는지, 왜 안 입는지 알기 어려움
    -   취향 변화와 유행 변화를 구분하기 힘듦

-   **AIoT 구현**

    -   **하드웨어:** 라즈베리파이 + 옷장 내부 또는 전신거울 상단 카메라
    -   **기능:**

        -   매일 착장 데이터를 기록하여 ‘착장 패턴’ 분석
        -   3개월 이상 선택되지 않은 옷 자동 추출

-   **AI 분석 결과 예시**

    -   “현재 유행과 맞지 않음”
    -   “체형 변화로 착용 시 불편함”

-   **젠킨스 가치**

    -   연간 트렌드 컬러, 핏 데이터 학습
    -   개인 옷이 ‘유행 문제’인지 ‘취향 변화’인지 판단

-   **사업성 확장**

    -   번개장터, 당근마켓 등 중고 거래 플랫폼 연동
    -   ‘안 입는 옷 바로 판매’ 기능

---

### [외출 효율] AI 의류 배치 최적화 — **Pick-N-Go**

> 아침 준비 시간을 줄이는 물리적 가이드형 추천 시스템

-   **불편함**

    -   옷장 안쪽 옷은 잊혀짐
    -   항상 손에 잡히는 옷만 반복 착용

-   **AIoT 구현**

    -   **하드웨어:**

        -   라즈베리파이
        -   저전력 **E-Ink 디스플레이** (옷걸이 / 서랍 부착)
        -   스마트폰 캘린더 연동

-   **AI 기능**

    -   다음 날 일정(TPO) + 날씨 분석
    -   전날 밤 미리 착장 추천

-   **물리적 안내**

    -   선택된 옷의 위치에 E-Ink로 “Pick” 표시

-   **젠킨스 가치**

    -   사용자의 실제 선택 데이터를 학습
    -   TPO 선호도 기반 추천 알고리즘 주기적 업데이트

---

#### 3) 기대 효과

-   아침 준비 시간 단축
-   반복 착장 감소
-   스타일 감각 보조 (1인 가구, 독거 생활자에게 유용)

---

#### 4) 구현 방법

-   컴퓨터 비전으로 의류 인식 및 색상 분석
-   상의 기준으로 하의, 자켓 추천
-   신발장 연동으로 전체 착장 완성
-   만족도 높은 코디 데이터는 서버에 저장 후 웹에서 확인

---

#### 5) 걱정되는 부분

-   옷 등록 시 겹침 문제
-   사진 등록 방식이 AIoT 취지와 맞는지 여부
-   카메라 기반 옷 위치 인식 정확도
-   신발장 내 신발 위치 추적 문제

---

### AI 과외 시스템

#### 1) 아이디어 설명

> 귀찮은 오답 노트를 **물리적인 행동**으로 해결하는 시스템

-   오답 노트를 앱으로 만드는 것은 진입장벽이 높음

-   대신 **틀린 문제를 봉투/상자에 넣는 방식**을 사용

-   **AIoT 구현**

    -   라즈베리파이 + 문서 스캐너 + 소형 영수증 프린터
    -   문제 스캔 → OCR → 서버 저장
    -   일주일 뒤 오답만 모아 ‘개인 시험지’ 출력

-   **젠킨스 가치**

    -   취약 단원 분석
    -   출력 오답의 우선순위 자동 조정

---

#### 2) 구현 방법

##### (1) 지능형 이미지 컷팅 전략

-   완벽한 텍스트 변환 대신 **문제 영역 분할**에 집중

-   **Object Detection**

    -   문제 번호 / 본문 / 수식 / 풀이 흔적 분리

-   **Image Processing**

    -   필기 흔적 제거 또는 흐림 처리
    -   문제 본문만 고화질로 추출
    -   수식은 이미지 그대로 저장 및 출력

---

##### (2) 젠킨스 기반 개인화 학습

-   **필기체 적응 학습**

    -   초기 샘플 필기 스캔 → OCR 미세조정

-   **수식 라이브러리 업데이트**

    -   최신 수식 모델을 TFLite로 경량화 배포
